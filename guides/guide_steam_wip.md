[h1]🛠️ Installation Facile & Rapide[/h1]

[h2]Méthode 1 : Installation automatique en 1 clic (Recommandé - Windows)[/h2]
[olist]
[*] Téléchargez l'archive [b]TornekosMysteryDungeon-Windows_Patch_FR_v1.0.zip[/b] ci-dessus.
[*] Décompressez l'archive sur votre ordinateur.
[*] Double-cliquez sur le fichier [b]installer.bat[/b].
[*] L'installateur détecte automatiquement votre jeu Steam, sauvegarde vos fichiers d'origine et installe le patch en 5 secondes !
[*] Lancez le jeu via Steam en vous assurant que la langue est sur [b]Anglais[/b] dans les options (le jeu sera intégralement en français).
[/olist]

[h2]Méthode 2 : Installation manuelle (Windows / Steam Deck / Linux)[/h2]
[olist]
[*] Ouvrez votre bibliothèque Steam.
[*] Clic droit sur le jeu > [b]Gérer[/b] > [b]Parcourir les fichiers locaux[/b].
[*] Rendez-vous dans le dossier :
[code]TornekosMysteryDungeon \ Content \ Paks[/code]
[*] [i](Conseil)[/i] Faites une copie de votre fichier original [b]TornekosMysteryDungeon-Windows.pak[/b] (renommez-le par exemple en [i].backup[/i]).
[*] Collez le nouveau fichier [b]TornekosMysteryDungeon-Windows.pak[/b] extrait de l'archive dans ce dossier.
[*] Lancez le jeu (avec la langue du jeu réglée sur [b]Anglais[/b] dans les paramètres).
[/olist]

[h2]🎮 Sur Steam Deck (SteamOS) :[/h2]
Passez en [b]Mode Bureau[/b], ouvrez le dossier du jeu via Steam (*Parcourir les fichiers locaux*), remplacez le fichier dans [code]TornekosMysteryDungeon/Content/Paks/[/code], puis repassez en [b]Mode Jeu[/b] !
